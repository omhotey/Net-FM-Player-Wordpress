# Проверка безопасности кандидата 0.3.0

Проверка выполнена 18.11.2026 для исходников плагина и WordPress Lab 7.1.4 / PHP 8.3.33. Это внутренняя проверка, не независимый аудит и не гарантия отсутствия уязвимостей.

## Проверено

- Страница настроек требует `manage_options`; сохранение использует WordPress Settings API и его nonce. В песочнице посетителю и синтетической роли editor вывод настроек и изменение настроек через REST отклонены.
- Публичный каталог регистрирует GET; POST к маршруту отклоняется. Отключённые для выбора станции в каталог не включаются.
- Тесты в WordPress подставили HTML в названия и `javascript:` в адреса: исполняемая разметка и опасная схема в вывод не попали. Настройки при тесте не сохранялись.
- Проверены сохранение старого формата и защита от усечённой формы; тестируемые настройки и страницы при изолированной установке и обновлении сохранились.
- В просмотренных исходниках плагина не обнаружены серверные HTTP-запросы к пользовательским URL, выполнение shell-команд, `eval` или запись метаданных через `innerHTML`. Plugin Check ранее сообщил об отсутствии ошибок в категории безопасности.

## Условия эксплуатации и ограничения

Каталог и параметры плеера публичны: названия, адреса потоков, API и обложек видны посетителю. Не вводить в них пароли, ключи или приватные URL. Браузер посетителя подключается к настроенным внешним серверам напрямую, поэтому владелец сайта должен доверять выбранному провайдеру потоков и метаданных.

Не выполнялись независимый пентест, анализ всех внешних компонентов сайта и инфраструктуры станции, а также исчерпывающие испытания всех сочетаний настроек и браузеров. При установке на конкретный сайт необходимы его обычные обновления, контроль прав администраторов и проверка конфигурации HTTPS.
