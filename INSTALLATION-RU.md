# Установка NET FM Player 0.3.0 — кандидат

Автор плагина — Юрий Струк (omhotey). Пакет `net-fm-player-0.3.0-test.zip` предназначен для проверки перед выпуском. Он требует WordPress 6.5 или новее и PHP 8.2 или новее; в песочнице проверена связка WordPress 7.1.4 / PHP 8.3.33.

## Установка и настройка

1. На тестовой копии сайта откройте «Плагины → Добавить новый → Загрузить плагин», выберите ZIP и активируйте плагин. Перед обновлением существующей установки обеспечьте возможность восстановления сайта и настроек.
2. Откройте «Настройки → NET FM Player». В карточке каждой станции задайте название, публичные URL потоков и, при наличии, адрес AzuraCast и идентификатор станции. Подпишите доступные потоки понятными слушателю названиями, например «128 кбит/с» и «320 кбит/с»; не добавляйте поток, которого у станции нет.
3. Отметьте станции, которые должны появляться в выборе на сайте, и сохраните настройки. Для старого шорткода без указания станции задайте также глобальный поток.
4. На странице добавьте блок NET FM Player, виджет Elementor или шорткод `[net_fm_player stations="all"]`. Для отдельной станции используйте `[net_fm_player station="station-id"]`; идентификатор указан в карточке станции. Для выбранного набора используйте `[net_fm_player stations="id-1,id-2"]`.
5. На опубликованной тестовой странице проверьте запуск и остановку, смену станции и качества, громкость, сведения о треке, мобильную раскладку и работу после обновления страницы. При двух потоках проверьте также резерв в контролируемом тестовом сценарии.

Длинное название прокручивается в одну строку. Щелчок правой кнопкой по названию или исполнителю либо долгое нажатие на телефоне открывает кнопку копирования. Доступ к буферу обмена зависит от браузера и безопасного соединения HTTPS.

Браузер посетителя обращается к указанным потокам и API напрямую: нужны доступные публичные адреса, подходящие CORS-настройки и HTTPS для сайта на HTTPS. Автовоспроизведение может ограничиваться браузером.

## Публичный каталог

`/wp-json/net-fm-player/v1/stations` доступен без авторизации и содержит включённые станции, адреса их потоков, API и обложек. Не помещайте пароли, токены или другие секреты в эти адреса. Каталог появится на том сайте, где плагин активирован; работа мобильного приложения с конкретным production-адресом требует отдельной настройки и проверки.

## Границы проверки кандидата

В WordPress Lab проверены Gutenberg, Elementor, несколько станций, выбор потока, резерв, отдельные проверки прав и экранирования, а также изолированная установка и обновление из локального ZIP. Проверки других версий WordPress и PHP владелец исключил из обязательных. Физический iPhone/Safari и полноценный аудит безопасности ещё не проверены. Не считайте этот пакет окончательным production-релизом до закрытия оставшихся проверок из `PRODUCTION-PLAN.md`.
