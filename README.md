# NET FM Player

WordPress-плагин для радиостанций AzuraCast и прямых аудиопотоков. Автор — Юрий Струк (omhotey). Лицензия: GPL-2.0-or-later.

Плеер добавляется шорткодом, блоком Gutenberg или виджетом Elementor. Станции и названия доступных потоков настраиваются в админке; слушатель может переключать включённые станции и качество. Публичный каталог станций доступен для совместимых приложений.

[Скачать NET FM Player](https://github.com/omhotey/net-fm-player/releases/latest) — установочный ZIP приложен к выпуску.

Начиная с 0.3.1 плагин проверяет стабильные выпуски GitHub через стандартный механизм WordPress. На странице «Плагины» можно включить автоматические обновления для NET FM Player. Если установлена версия 0.3.0 или более ранняя, сначала обновите её один раз через ZIP: в этих версиях механизма ещё нет. Предварительные выпуски автоматически не устанавливаются.

После переименования репозитория установленную 0.3.1 также следует один раз обновить вручную: её проверка доверяет только прежнему адресу архива. Версия 0.3.2 использует новый адрес GitHub.

Установка и настройка описаны в [INSTALLATION-RU.md](INSTALLATION-RU.md), фактические проверки и оставшиеся ограничения — в [PRODUCTION-PLAN.md](PRODUCTION-PLAN.md), результаты проверки безопасности — в [SECURITY-REVIEW.md](SECURITY-REVIEW.md). `PRD.md` и `ROADMAP.md` сохраняют историю и последующие планы; возможности проверяемого пакета описаны в инструкции и плане выпуска.

Аудиопотоки и API запрашиваются браузером посетителя. Все адреса, публикуемые плеером и каталогом, должны быть публичными и не содержать секретов.

В версии 0.3.2 кнопка Auto скрыта: выбирается поток с подписью 128 кбит/с, если он настроен, иначе первый доступный обычный поток. Настройки HLS сохраняются. Количество кнопок соответствует количеству обычных потоков станции.

В совместимых браузерах экспериментальный транспорт читает звук и метки ICY из одного соединения. Обложка выбирается по однозначному совпадению с AzuraCast; при недоступности транспорта используется прямой поток и метаданные API. Точная синхронизация при любых условиях, браузерах и на физических устройствах ещё не подтверждена. Проверки и открытые вопросы указаны в плане выпуска.
