# NET FM Player

WordPress-плагин для радиостанций AzuraCast и прямых аудиопотоков. Автор — Юрий Струк (omhotey). Лицензия: GPL-2.0-or-later.

Плеер добавляется шорткодом, блоком Gutenberg или виджетом Elementor. Станции и названия доступных потоков настраиваются в админке; слушатель может переключать включённые станции и качество. Публичный каталог станций доступен для совместимых приложений.

Установка и настройка описаны в [INSTALLATION-RU.md](INSTALLATION-RU.md), фактические проверки и оставшиеся ограничения — в [PRODUCTION-PLAN.md](PRODUCTION-PLAN.md). `PRD.md` и `ROADMAP.md` сохраняют историю и последующие планы; возможности проверяемого пакета описаны в инструкции и плане выпуска.

Аудиопотоки и API запрашиваются браузером посетителя. Все адреса, публикуемые плеером и каталогом, должны быть публичными и не содержать секретов.
